## リポジトリ名とGitHub Pages URL


通常のGitHub Pages URLは次の形になる。

```text
https://GitHubユーザー名.github.io/リポジトリ名/
```

例：

```text
https://amber00tiger.github.io/vaps/
```

リポジトリ名を `GitHubユーザー名.github.io` にした場合だけ、URLは次のように短くなる。

```text
https://GitHubユーザー名.github.io/
```

`vaps` リポジトリで公開する場合、GitHub Pagesでは `/vaps/` 配下で動く。GitHub Actionsなどの本番ビルドでは `NEXT_PUBLIC_SITE_BASE_PATH=/vaps` を設定する。

## GitHub Pagesに載せる環境変数

GitHub Actionsでビルドする場合、Repository variables または workflow の `env` に以下を入れる。

```text
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
NEXT_PUBLIC_DISCORD_COMMUNITY_URL
NEXT_PUBLIC_SITE_BASE_PATH
```

これらはブラウザに公開される値。`service_role key` は入れない。

`NEXT_PUBLIC_SITE_BASE_PATH` はGitHub Pages用ビルドでは次にする。

```text
/vaps
```

ローカル開発では空のままでよい。
